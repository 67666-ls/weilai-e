# 腾讯校招主要岗位与职责

> 来源：腾讯校招官网（join.qq.com）公开 JD 及历年宣讲会信息整理。仅作 AI 陪伴体内部检索使用。

## 一、技术类

### 后台开发
- 关键词：C++ / Go / Java / 分布式 / 高并发 / 微服务
- 典型任务：业务后台逻辑、性能优化、稳定性建设。
- 加分项：开源贡献、ACM/PAT、参与过线上系统的实习。

### 前端开发
- 关键词：JavaScript / TypeScript / React / Vue / 工程化
- 典型任务：业务前端、低代码平台、工具链优化。
- 加分项：开源组件、个人技术博客、复杂交互项目。

### 客户端开发（iOS/Android/PC）
- 关键词：性能、内存、热修复、跨端框架。
- 典型任务：QQ、微信、腾讯视频等 App 端的功能与优化。

### 算法/AI
- 关键词：机器学习、推荐、CV、NLP、大模型。
- 典型任务：推荐排序、广告 CTR、内容理解、多模态。
- 加分项：顶会论文、Kaggle 排名、过硬数学功底。

### 数据开发/数据分析
- 关键词：SQL、ETL、Hadoop/Spark、A/B 实验。
- 典型任务：数据仓库建设、BI 报表、增长实验。

### 运维/安全
- 关键词：Linux、网络、Web 安全、攻防演练。

## 二、产品类

### 产品策划/产品经理
- 关键词：用户研究、需求文档、数据分析、产品迭代。
- 典型任务：写 PRD、跑数据、推进版本、用户访谈。
- 加分项：从 0-1 做过产品（小程序/Side Project 都算）、商业化案例分析。

### 商业化产品
- 关键词：广告、电商、增长、变现策略。

## 三、设计类

### 视觉/交互/用户研究
- 关键词：Figma、用户旅程、可用性测试。

## 四、市场/运营/内容

### 内容运营
- 关键词：内容策划、社区管理、KOL 合作。

### 市场公关
- 关键词：品牌传播、媒介投放、活动策划。

## 五、职能类

- 财务、法务、人力资源、行政、战略投资。

## 六、面向「未来鹅」AI 的回答策略

- 学生说"我学计算机"→ 优先后台/前端/客户端/数据/算法五条线介绍。
- 学生说"我喜欢和用户打交道"→ 产品经理 / 用户研究 / 内容运营。
- 学生说"我数学好"→ 算法 / 数据。
- 学生说"我跨专业"→ 产品 / 运营 / 设计 / 职能里挑切入点。
