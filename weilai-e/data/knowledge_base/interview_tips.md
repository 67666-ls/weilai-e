# 腾讯面试常见考察点与提示

> 综合自候选人公开复盘、宣讲会面试官分享。仅供「未来鹅」AI 内部参考。

## 通用考察维度

| 维度 | 怎么考 | 学生准备 |
|------|--------|---------|
| 项目深度 | 让你讲一个项目，连环追问 | 用 STAR 写 3 个最得意的项目，自己提前演练 |
| 基础知识 | 操作系统 / 网络 / 数据库 / 算法 | 八股 + 手写代码 |
| 思考方式 | 给一个开放问题，看分析过程 | 大声思考、先澄清再答 |
| 价值观契合 | 行为题（团队冲突 / 失败经历） | 用真实案例，避免编 |
| 长期潜力 | 你想 3-5 年做什么 | 提前想清楚，但允许"我还在探索" |

## 技术岗高频题

- 操作系统：进程/线程、内存管理、IO 模型。
- 网络：TCP 三/四次握手、HTTP/HTTPS、TLS。
- 数据库：索引（B+Tree）、隔离级别、慢查询。
- 算法：链表、二叉树、动态规划、堆/栈。手写代码必考。

## 产品岗高频题

- 产品分析：选一款你常用的产品，说核心指标和增长点。
- 用户体验：找一个体验差的功能，给改进方案。
- 数据：DAU 突然下跌 20%，怎么排查？
- 商业化：如何评估某功能能否变现。

## 设计岗高频题

- 一个交互体验有问题的场景，怎么改？
- 设计稿的 3 个版本，你为什么选 B？
- 走查作品集时，每页准备好"我做了什么 / 为什么这么做 / 如果重做我会怎样"。

## 行为题套路（STAR）

- **S**ituation：背景（一句话）。
- **T**ask：你的任务（一句话）。
- **A**ction：你具体做了什么（重点，2-3 个动作）。
- **R**esult：量化结果（数字 + 自我反思）。

## 反问环节

学生常忘了反问，建议准备 2-3 个：

1. 这个岗位最近一年最大的挑战是什么？
2. 您对这个岗位的实习生有什么期望？
3. 如果我入职，前 3 个月可能会做什么？

## 「未来鹅」AI 在面试陪练时的输出结构

每轮 1 个问题，学生答完后给：
1. 复述要点；
2. 2 条优点；
3. 2 条改进；
4. 样例答案要点（不要给完整范文，否则学生会照背）。
