# 腾讯实习项目指南（青云计划 / 犀牛鸟 / 暑期实习）

> 来源：腾讯校招官网公开材料整理，时间窗口及流程仅作演示，实际请以当年招聘官网为准。

## 主流通道

| 项目 | 面向 | 时间窗口（历史规律） | 备注 |
|------|------|--------------------|------|
| 暑期实习（最主流） | 大三、研一为主 | 3 月开放 → 5 月入职 | 大概率转正 |
| 日常实习 | 全年级 | 全年滚动 | 灵活，部分可远程 |
| 青云计划 | 顶尖高校 + 顶级技术能力 | 暑期前提前批 | 算法/技术研究方向 |
| 犀牛鸟精英 | 大二/大三 + 科研背景 | 春季 | 偏研究 |

## 流程

1. 投递（官网 + 内推码并行）。
2. 简历筛选。
3. 笔试（技术岗有；产品岗以测评 + 题目为主）。
4. 一面（业务/技术深挖）。
5. 二面（leader 面，看潜力和契合度）。
6. HR 面 / Offer 沟通。

## 实习准备清单

- **简历**：1 页，重点项目用 STAR 写，量化结果。
- **作品集**：技术岗放 GitHub；产品岗放 PRD + 数据案例。
- **基础功**：算法岗复习 ML 基础 + 八股；后台复习操作系统 / 网络 / 数据库 / 算法。
- **行业洞察**：能讲清楚目标 BG 在做什么，最近一年有什么大动作。

## 内推

- 找认识的鹅厂在职/前员工内推码（合规渠道）。
- 内推不能保证过简历，但能加速审核。

## 「未来鹅」AI 回答指引

- 学生问"什么时候投"→ 给当年时间窗口 + 1 个月预留准备期。
- 学生问"实习能转正吗"→ 大方向是「表现好可转正」，但不做承诺。
- 学生问"没经验能投吗"→ 鼓励先投日常实习 / 中小厂打底。
