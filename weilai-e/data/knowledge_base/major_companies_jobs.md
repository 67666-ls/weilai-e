# 主要互联网/科技公司校招岗位速查

> 来源：各公司官方校招网站（job.bytedance.com、campus.alibaba.com、talent.baidu.com、campus.meituan.com 等）公开 JD 与历年宣讲会信息整理。仅作 AI 陪伴体内部检索使用，所有信息以当年官方公告为准。

## 一、字节跳动（ByteDance）

### 公司定位
抖音、TikTok、今日头条、剪映、飞书母公司。校招盘子最大、节奏最快的公司之一，秋招提前批一般 7 月开。

### 主要岗位
- **后端开发**：Go / C++ / Java；服务大流量推荐、广告、电商系统。
- **前端开发**：React / TypeScript；飞书、抖音中后台、TikTok Web。
- **客户端开发**：Android / iOS；抖音、TikTok 主端，对性能、包大小要求极高。
- **算法工程师**：推荐、广告、CV、NLP、大模型；要求最高，常要求顶会论文或竞赛排名。
- **数据分析/数据科学**：业务策略、增长实验、A/B test；面试侧重 SQL + Case。
- **产品经理**：抖音、TikTok、剪映、电商、教育；面试重数据感和用户洞察。
- **运营**：内容运营、商业化运营、海外运营；TikTok 海外运营有英语门槛。
- **设计**：UI/UX、品牌、动效；作品集硬门槛。

### 校招特点
- 业内闻名的"赛马"和高强度文化，但成长快、薪资同梯队最高之一。
- 面试普遍 3-4 轮 + HR 面，偏 case 推演 + 现场算法（技术岗）。
- 实习转正比例高，建议大三尽量拿到日常实习/暑期实习。

## 二、阿里巴巴（含淘天、阿里云、蚂蚁、菜鸟、本地生活）

### 公司定位
电商根基（淘天）、云计算（阿里云）、金融科技（蚂蚁）、物流（菜鸟）、本地生活（饿了么/高德）。校招按 BU 分别招聘。

### 主要岗位
- **Java 后端**：阿里历史最强的方向，Java 生态、中间件、分布式经验加分。
- **算法工程师**：搜索、推荐、广告、风控、大模型；蚂蚁的安全/风控算法是特色。
- **前端**：React/Vue 都用，阿里也是主要的开源前端贡献者（Ant Design、UmiJS）。
- **客户端**：手淘、支付宝主端开发。
- **数据**：MaxCompute 生态、BI、数据科学。
- **产品**：淘天产品偏交易和增长；蚂蚁产品重风控和合规；阿里云产品偏 ToB。
- **运营**：电商运营、商家运营、海外运营。
- **设计**：阿里 UED 体系成熟，作品集要求高。

### 校招特点
- 强调价值观面试（"闻味官"），HR 终面权重大。
- 蚂蚁、阿里云薪资普遍高于淘天主体。
- 大三暑期实习（俗称"阿里星"）含金量高。

## 三、腾讯

### 公司定位
微信、QQ、王者荣耀/和平精英、视频号、企业微信、腾讯云、PCG（视频/新闻）、CSIG（云与产业互联网）。

### 主要岗位
- **后台开发**：C++ 是腾讯老牌强势方向，Go 也大量使用。
- **客户端开发**：微信、QQ、腾讯视频、王者荣耀客户端。
- **游戏开发**：IEG 是国内顶级游戏研发体系，引擎/服务器/工具链都招。
- **算法**：广告、推荐、游戏 AI、大模型；广告算法薪资天花板。
- **前端**：微信小程序、企业微信、PCG 业务前端。
- **产品**：微信、视频号、游戏策划是热门；游戏策划独立招聘体系。
- **运营**：内容运营、社区运营、游戏运营。
- **设计**：CDC（用户研究中心）和 ISUX（社交用户体验设计部）业内知名。

### 校招特点
- 文化"正直、进取、协作、创造"，价值观面试题型相对柔和。
- 实习转正比例高，建议大三抢暑期实习。
- 业务多元，不同 BG 节奏和氛围差异大。

## 四、美团

### 公司定位
外卖、到店、酒旅、买菜、闪购、无人机、自动驾驶。地图（与高德竞争）、配送系统、机器学习是技术重点。

### 主要岗位
- **后端开发**：Java 为主，海量并发、订单履约、调度系统。
- **算法**：配送调度（业内独家场景）、推荐、广告、CV（识别证照、菜品）。
- **客户端**：外卖、点评、骑手端 App；骑手端对低端机和弱网有特殊优化。
- **数据**：交易数据、运营数据；BI 工具链自研。
- **产品**：到店产品、外卖产品、骑手产品（B 端复杂业务）。
- **运营**：城市运营是美团特色岗位，需要下沉到城市做地推 + 数据策略。
- **金融**：美团金融、信贷风控。

### 校招特点
- "战斗文化"，节奏快、城市岗位需要下沉一线。
- 算法薪资和字节阿里同梯队，业务强算法深。
- 城市经理/运营管培生也是热门通道。

## 五、百度

### 公司定位
搜索、文心一言（大模型）、自动驾驶（Apollo）、智能云、百度地图。AI 原生公司。

### 主要岗位
- **算法工程师**：NLP、大模型、CV、自动驾驶感知/规控；文心 / Apollo 是技术亮点。
- **后端开发**：C++、Go；搜索引擎、广告系统老牌强项。
- **前端**：搜索结果页、智能云控制台。
- **客户端**：百度 App、地图、网盘。
- **数据**：搜索数据、用户行为数据。
- **产品**：搜索产品、文心一言产品、地图产品。

### 校招特点
- AI 方向校招招聘量大，对论文和竞赛认可度高。
- 自动驾驶有独立招聘通道，硬件 + 算法都招。
- 薪资普遍略低于字节/腾讯/阿里头部，但 AI/大模型方向有竞争力 offer。

## 六、京东

### 公司定位
电商、物流（京东物流）、健康、工业。供应链 + 自营是核心。

### 主要岗位
- **Java 后端**：交易、库存、供应链系统。
- **算法**：搜索、推荐、供应链优化（运筹学背景加分）、风控。
- **前端**、**客户端**：京东 App、PLUS 会员、采销系统。
- **产品**：B 端供应链产品、C 端电商产品。
- **运营**：采销岗位独特，对接品牌方 + 数据 + 营销。
- **物流**：京东物流单独招聘，运筹优化、自动化、机器人方向。

### 校招特点
- 采销/管培是京东特色通道，培养接班人节奏。
- 整体薪资低于字节阿里梯队，但稳定性好。

## 七、拼多多

### 公司定位
主站、Temu（海外）、多多买菜、拼多多金融。Temu 是近年校招重点。

### 主要岗位
- **后端**：Java/Go；订单、广告、风控系统。
- **算法**：搜索、推荐、广告、风控；薪资同业前列。
- **客户端**：主站 App、Temu App。
- **海外运营 / Temu 运营**：Temu 业务扩张快，对英语和跨境电商感兴趣的同学是机会。
- **产品**：主站产品、海外产品。

### 校招特点
- 业内最高薪之一，但工作强度也是业内最高之一。
- 面试节奏快，技术岗算法题硬核。
- 应届生 package 普遍领先，但晋升节奏快、压力大。

## 八、网易

### 公司定位
游戏（网易雷火、网易互娱）、有道（教育）、严选、网易云音乐、网易新闻。

### 主要岗位
- **游戏开发**：客户端、服务器、引擎、游戏 AI；网易游戏校招独立通道、薪资业内顶级。
- **后端**：Java/Go；电商、音乐、有道业务后端。
- **算法**：推荐（云音乐、新闻）、游戏 AI、教育 AI。
- **客户端**：云音乐、有道词典 App。
- **产品**：游戏策划是主力岗位，分系统/数值/剧情；非游戏产品招得相对少。
- **设计**：游戏美术、UI/UX。

### 校招特点
- 游戏方向独立招聘体系，薪资与互联网大厂可比。
- 杭州为主，部分岗位北京/广州。
- 工作氛围相对温和，适合追求平衡的同学。

## 九、华为

### 公司定位
通信设备、消费者业务（手机、平板、智能穿戴）、HarmonyOS、华为云、智能汽车（车 BU）。

### 主要岗位
- **嵌入式 / 操作系统开发**：HarmonyOS、芯片驱动；C/C++ 硬核要求。
- **通信协议开发**：5G/6G、传输；EE/通信专业方向。
- **AI 算法**：盘古大模型、自动驾驶感知/规控。
- **后端**：华为云、消费者云。
- **硬件研发**：芯片、整机、天线；EE 专业重点。
- **测试 / 运维**：华为对测试岗位招聘量大。

### 校招特点
- TOP 学校优先，"天才少年"计划薪资最高可达 200w+/年。
- 普通校招走 13/15/17/19 级体系，14/15 级是应届生主流。
- 加班"奋斗者"文化，海外岗位补贴高。
- 适合做底层、硬件、通信方向的同学。

## 用法提示

- **学生提到具体公司名时**：用本知识库给出该公司岗位 + 校招特点。
- **学生没指定公司、问"哪些公司适合我"时**：根据学生年级/专业/兴趣，对比 3-4 家不同梯队的公司（例如：算法方向 → 字节 + 阿里 + 百度；游戏方向 → 腾讯 IEG + 网易游戏 + 米哈游）。
- **学生问薪资时**：给出梯队描述（"业内顶级 / 头部 / 中上 / 中等"），不给具体数字承诺。
- **不要黑任何公司**：客观说强项和工作强度，让学生自己判断。
