# 未来鹅 · 手动测试脚本

> 按"功能勾稽"设计,从打开 app 一直跑到所有 tab 都长出内容,大约 15 步,15-20 分钟跑完。
> 每步标了 → **期望看到的**,出问题就知道是哪一环。

---

## 准备

**Step 0 · 侧边栏填画像**

- 年级:`大三`
- 专业 / 学校:`某 211 计算机科学`
- 兴趣方向:勾选 `互联网产品`、`后台`(这两项决定后面雷达图叠加哪个"岗位要求")
- 备注:`想试试产品岗,但担心非科班背景`

→ **期望**:右侧"当前 Agent"灰色("尚未路由");LLM 已就绪

> 💡 提醒:第一次进来,memory 里既无经历卡又未结束访谈,router 应该自动选 `interviewer`。如果你之前测过、`weilai-e/data/memory/<user_id>.json` 已经有数据,先点侧边栏「🧹 重置当前会话」并删掉对应 json 文件,确保是冷启动。

---

## 场景 1:反向访谈 → 沉淀 4 类卡片(测 interviewer + `<card>` 解析)

**Step 1**

```
你好,这是什么产品?
```

→ **期望**:Agent 标签 = 反向访谈;AI 主动问"说一件你大学里挺有成就感的事";正文里**不应该看到** `<card>` 标签(被后端剥离了)。

**Step 2**

```
大二暑假,我们三个人做了一个校园二手平台,我主要负责后端,
设计了订单和评价两张表,接了支付宝沙箱,日活 200 左右。
```

→ **期望**:AI 用 STAR 子集追问"几个人?具体负责啥?";后端默默写入一张 `experience` 卡(period=大二·暑假,role=后端,result=日活 200)+ skills(项目推动 / 技术深度 各 4 分左右)。

**Step 3**

```
我负责接口设计和数据库表结构,跟前端同学每天对接 API,
中间因为支付回调签名问题熬了两个通宵才修好。
```

→ **期望**:AI 继续追问;skills 应该新增/更新「沟通表达」、「抗压」两个维度。

**Step 4**

```
那段时间我自己也读了好几篇产品复盘文章,
对二手交易这个赛道做了点竞品分析,看了闲鱼、转转、孔夫子的数据。
```

→ **期望**:skills 新增「数据分析」「行业认知」(到这步 6 维就齐了,雷达图能成形)。

**Step 5 · 触发纠结卡**

```
其实我现在最纠结的就是,想做产品但不是产品科班,
也没产品实习,不知道大三还能不能转。
```

→ **期望**:写入 `struggle` 卡(内容 ≈ 想做产品但担心非科班背景)。

**Step 6 · 收口 + 触发 task**

```
够了,先这样,你帮我定本周要做的事吧。
```

→ **期望**:
- AI 回复包含"画像差不多有了..."
- `<card>` 里带 `interview_done: true` + `tasks: [...]`
- **`memory.interview_done` 置位**;后续不再走 interviewer
- **主区顶部"🎯 今日行动板"出现 1-2 条 pending 任务**(by 反向访谈)

## 场景 2:验证四个 tab(刷新/折叠展开 expander)

点开「📒 我的画像 & 成长记录」,逐个 tab 看:

| Tab | 期望看到 |
|---|---|
| 🪪 当前画像 | 年级=大三、专业、兴趣、备注 |
| 📜 成长记录(N) | 5-6 条按时间倒序的对话摘要 |
| 📋 素材卡(1/4-6/1) | 1 张经历卡 + 4-6 张能力卡 + 1 张纠结卡 |
| 📈 能力雷达 | 蓝色"我的能力"5-6 边形 + 黄色虚线"后端 岗位要求"叠加 |

> 💡 雷达没出现要么是 plotly 没装(降级成星级文本),要么是 skills 全 0(LLM 没产出 skills)。

## 场景 3:测试其他 4 个 Agent 路由

interview_done 已置位,后面应该按关键词分流:

**Step 7 · explorer**

```
其实我对方向有点迷茫,产品和后台都想试试,什么岗位适合我?
```

→ Agent = 探索向导(命中"迷茫" / "什么岗位")

**Step 8 · intern**

```
那大三这个阶段,作品集应该怎么准备?暑期实习有哪些可以投?
```

→ Agent = 实习导航(命中"作品集 / 暑期");工具栏会有岗位推荐

**Step 9 · coach**

```
顺便问下,秋招时间线是怎样?简历要怎么改一下?
```

→ Agent = 求职教练("秋招"+ 大三/简历→ coach);工具栏会有 resume_analyzer + 知识库

**Step 10 · mock**

```
出题吧,给我一道产品经理的行为题,STAR 框架。
```

→ Agent = 面试陪练(命中"出题")

**Step 11 · interviewer 关键词覆盖默认**

```
学长再帮我做一次画像吧,采访我一下。
```

→ Agent = 反向访谈(显式关键词命中,即使 interview_done 也能进)

## 场景 4:行动板交互

回到主区顶部行动板:

**Step 12** · 点其中一条任务的 `✅ 完成`

→ **期望**:toast"已标记为完成 ✅";rerun 后这条消失;`memory.tasks[k].status = "done"`

**Step 13** · 点剩下任意一条的 `⏭️ 跳过`

→ **期望**:同上,标记为 skipped;消失

**Step 14** · 全部清空后,看空态

→ **期望**:行动板显示"还没有目标,去聊一聊学长会帮你定。"

---

## 场景 5:跨会话追问(机制 2 的核心差异点)

**Step 15 · 重置会话(模拟用户关浏览器再回来)**

侧边栏点 `🧹 重置当前会话`(注意:这只清 chat_history,**不清 memory**——这正是跨会话追问的前提)

如果你 Step 12-13 全把任务点掉了,先在 Step 6 的对话里再要一次新任务:

```
再帮我加一条本周任务,周日前投出 2 个产品实习。
```

然后重置会话,随便说一句:

```
你好。
```

→ **期望**:AI 第一句话主动追问上次的 pending 任务,例如"上次说要投 2 个产品实习,投出去了吗?"——这是 `render_pending_tasks_prompt` 注入到 system 的效果。

## 失败排查速查

| 现象 | 大概率原因 |
|---|---|
| Agent 一直是反向访谈,关键词都不灵 | `memory.interview_done` 没置位;手工把 json 里这个字段改成 true 再试 |
| 素材卡 tab 一直空 | LLM 没按 prompt 输出 `<card>...</card>`;打开 `data/memory/<user_id>.json` 看 experiences/skills 字段是不是空 |
| 雷达图 6 维都是 0 | LLM 给的 skills 名字没命中 6 维白名单;看 json 里 skills.name 是不是「项目推动 / 数据分析 / 沟通表达 / 技术深度 / 行业认知 / 抗压」之一 |
| 雷达图没叠加岗位要求 | profile.target_roles 和 interests 都没匹配上 7 个内置职类(产品/后端/前端/算法/数据/运营/设计) |
| 跨会话追问没出现 | pending_tasks 列表是空的;先确认有 status=pending 的 task |
| 对话后主区一片空白 | 三层兜底已加;看 `data/memory/<user_id>.json` 是否更新过判断 LLM 是不是真的返回了内容 |
